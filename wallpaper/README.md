# Wallpaper

Pick a background picture, pane opacity, and border color in Herdr.

Open with `ctrl-a w`. Arrows or hjkl preview pictures. Enter advances to opacity, then borders, then saves. Esc restores the previous appearance. Press `f` to choose a picture folder. The default is `~/Pictures/herdr`, and your folder choice is remembered.

## Install

Copy or symlink `mods/wallpaper` into `~/.config/herdr-app/mods/wallpaper`, then merge [`keys.json`](keys.json) into Herdr's `keys.json`.
