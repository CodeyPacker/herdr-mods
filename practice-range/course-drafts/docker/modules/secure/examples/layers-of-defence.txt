  | default: root, writable files, default capabilities            |

  |  +----------------------------------------------------------+  |

  |  |  |   no new privileges, memory limit                  |  |  |
  |  |  |                                                    |  |  |
  |  |  |  +----------------------------------------------+  |  |  |
  |  |  |  | + small image: no shell tools to use         |  |  |  |
  |  |  |  +----------------------------------------------+  |  |  |
  |  |  +----------------------------------------------------+  |  |
  |  +----------------------------------------------------------+  |
  +----------------------------------------------------------------+
  Each ring leaves the attacker with less.
